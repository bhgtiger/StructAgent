# Decision trees

Request asks about a monomer or protein complex?
- Yes: explain appropriate input grammar and confidence limits.
- No / ligand, DNA, RNA, alternate model, AF3: identify it as out of v0 scope.

Request needs a command plan?
- Yes: establish version, environment, data sensitivity, MSA route, model purpose, and expected output. Return NOT RUN.
- No: answer conceptually with source boundary.

Request asks to install or execute?
- State v0 cannot execute. Explain that future execution requires explicit user authorization, a pinned runtime, live help/fixture validation, privacy approval, compute budget, paths, and destructive-option confirmation.

Request claims high confidence proves a result?
- Correct it: pLDDT is local confidence; for complexes assess PAE/interface metrics and independent validation.

Request proposes public MSA?
- State sequence egress and unknown retention terms. Fair-use source warning asks for serial submissions from a single IP. No remote action in v0.

Request proposes local MSA databases?
- State it is resource-heavy infrastructure, not a quick personal offline setup.
